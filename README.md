## About

Based on Chapter 121 (or thereabouts) of Battle Angel Alita: Last Order.  
You have 8 people under your care, and no information to help you save anyone.  
This is pure luck... or is it?

## Rules

- Start with 8 lives (including yourself)
- You start with 16 buttons initially (8 Rescue, 8 Death)
- You have 30 seconds to press a button, or a random person dies
- Each pressed button removes a button of the type pressed
- After Round 4, a Merciless button appears (💀)
- The Merciless button kills a random non-player character
- If you die, everyone dies
- Survive 8 rounds to win

## Other Notes

- There is a graph showing how many times you've saved how many people, including the times you've died, killing everyone.
